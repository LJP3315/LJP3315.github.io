## 代码块复制按钮增强

**背景**：用户希望代码块右上角的"复制"按钮更明显。排查发现该功能本就已存在并已启用（minimal-mistakes 内置），只是视觉上不显眼。

**现有实现链路（排查结论，后续排查同类问题可直接参考）**
- `_config.yml:33` → `enable_copy_code_button : true`（开关）
- `_includes/head.html:15-17` → 注入 `window.enable_copy_code_button = true`
- `assets/js/_main.js:146-233` → 按钮逻辑源码；**页面实际加载的是 `assets/js/main.min.js`**（`_includes/scripts.html:7`），改源码必须用 uglify 重新构建才生效
- 注入选择器：`.page__content pre.highlight > code`（`_main.js:218`）→ 只对**围栏代码块**生效，`{% highlight %}` 产生的 `<figure class="highlight">` 不会加按钮
- 样式：`_sass/minimal-mistakes/_utilities.scss:513-582`；定位基准 `_sass/minimal-mistakes/_syntax.scss:5-7`（`div.highlighter-rouge, figure.highlight { position: relative }`）
- 内容容器：`_layouts/single.html:43`（`.page__content`）

**不显眼的根因**：主题默认 `color: #ffffca`（浅黄）+ `opacity: 0.4`，在本站浅灰代码块（`.highlight` 背景 `#eeeeee`）上对比度极低，且不悬停时几乎不可见。

**改动**：仅修改 `assets/css/main.scss`（在文件末尾追加覆盖块，不动主题源码，无需构建）。
- 按钮常驻可见（`opacity: 1`），改为白底 + `#d0d7de` 描边 + 圆角的 chip 样式
- 图标由 `position: absolute` 改为 `position: static`，参与 flex 布局
- 用 `::after` 增加可见文字标签"复制"／复制后"已复制"
- 复制成功态：绿色对勾 + 绿底
- 位置仍在右上角（沿用主题的 `top: 0.6em; inset-inline-end: 0.5em`）

**验证方式**：本地无 sass/jekyll，改用 dart-sass（装在 `~/.workbuddy/binaries/node/workspace`）剥离 YAML front matter + 替换 Liquid 后编译 `main.scss`，通过；并确认自定义规则排在主题规则之后（同优先级下后者生效）。`git status` 仅 `assets/css/main.scss` 一处改动。

**注意**：`.no-copy pre .clipboard-copy-button { display: none }`（主题规则，优先级更高）仍能正常隐藏按钮——因此本次没有对 `display` 使用 `!important`，保留了该行为。
