## 追加改动：改为纯文字按钮 + 复制成功浮层

用户要求：按钮做成"一个写着'复制'的框"，复制成功时弹提示。

**改动文件（2 个）**
- `assets/css/main.scss`
  - 按钮改为纯文字：`i { display: none !important }` 隐藏主题自带的两个图标，仅靠 `&::after { content: "复制" }` 显示文字
  - `.copied` 仅保留绿色变色（不再切换成"已复制"文案）
  - 新增 `#copy-toast` 浮层样式（fixed 底部居中、白底绿边、`opacity/visibility/transform` 过渡）与 `.copy-toast__icon` 绿色圆底
- `_includes/scripts.html`（追加在文件末尾的 `<script>`）
  - 用 `MutationObserver` 监听 `document.body` 的 `class` 属性变化（`subtree: true, attributeFilter: ["class"]`）
  - 当某元素同时具备 `clipboard-copy-button` 与 `copied` 类时触发 toast
  - toast 节点懒创建、复用；1.8s 后自动隐藏

**为什么用 MutationObserver 而不是自己再绑一次 click**：主题脚本 `_main.js:206` 在复制成功时会给按钮加 `.copied`（1500ms 后移除）。监听这个类变化既能准确对应"复制成功"，又不需要重写/重复调用复制逻辑。而且监听 `document.body` 子树不依赖脚本执行顺序（主题脚本按钮注入发生在 `$(document).ready`，晚于本脚本执行）。

**验证**：dart-sass 编译通过；`node --check` 校验 JS 语法通过；用 jsdom 做了运行时验证（模拟主题脚本加 `.copied`）——toast 正确创建、文案"复制成功"、带勾选图标、1.8s 自动隐藏、重复复制复用同一节点，全部 PASS。
