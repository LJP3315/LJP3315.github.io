PS: Java实验7的主要内容，主要是使用数据库进行数据持久化

```xml
<!--添加数据库连接依赖-->
<dependency>
   <groupId>mysql</groupId>
       <artifactId>mysql-connector-java</artifactId>
   <version>8.0.33</version>
</dependency>
```

在使用数据库之前，在 pom.xml 文件添加连接依赖

```bash
1、	编写一个UserBean类，要求该类具有两个属性name和password，并给出两个属性对应的getter和setter方法。
2、	在MySQL数据库中新建ljp数据库，并建立名为users的用户信息表，users表包括name和password两个属性，此两个属性均为varchar(50)类型，均不为空，name为主键。
3、	编写主页面index.jsp，该页面提供两个超链接，分别链接到注册页面和登录页面；
4、	编写一个注册页面register.jsp，包括：用户名，密码，密码确认以及确认和重设按钮；
5、	编写一个登录页面login.jsp，包括：用户名，密码以及确认和重设按钮；
6、	注册处理Servlet：treatRegister.java。该Servlet判断用户名和密码是否为空、密码和密码确认是否相同。如果用户名和密码不为空且密码和密码确认相同，则认为注册成功，并将用户的姓名和密码存入到数据库ljp的users表中。否则认为注册失败。处理结果交给registerResult.jsp显示。
7、	登录处理Servlet：treatLogin.java。该Servlet判断判断用户名和密码是否为空，若不为空，在数据库ljp的users表中查询用户名和密码是否匹配。如果匹配则认为登录成功，生成UserBean对象user，在session对象以“user”的名字存入。其它情况均认为登录失败。处理结果交给loginResult.jsp显示。

```
